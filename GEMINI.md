# Talkinexx Project Styling Guidelines

When creating new pages or components for the Talkinexx project, strictly adhere to the following styling and theme algorithms:

## Color Palette
- **Primary Theme Green**: `#22C55E`
- **Dark Theme Blue**: `#12263A` (used for heavy emphasis, main headings, and dark backgrounds)
- **Neutral Light Border**: `#E2E8F0`
- **Neutral Text**: `#57534E` (for standard paragraphs)
- **Backgrounds**: Use `#fff` for standard sections, or subtle tinted backgrounds like `#F0FDF4` (very light green) for alternate sections like CTAs.

## Typography
- **Headings (h1, h2, etc.)**: 
  - Color: `#12263A`
  - Font Weight: `800` (Extra Bold) or `700`
  - Letter Spacing: Tight (e.g., `-1px`)
- **Body Text**:
  - Color: `#57534E`
  - Font Size: Generally `1.15rem` or slightly larger for readable marketing copy.

## Buttons
- **Primary Buttons**: 
  - Background: `#22C55E`
  - Text Color: `#fff`
  - Hover State: Add `transform: translateY(-3px)` and a subtle matching colored shadow `boxShadow: 0 10px 20px rgba(34,197,94,0.2)`.
- **Secondary (Outline) Buttons**:
  - Background: `#fff`
  - Text Color: `#12263A`
  - Border: `1px solid #E2E8F0`
  - Hover State: Background changes to `#12263A`, Text changes to `#fff`, border changes to `#12263A`.
- **General Button Styling**:
  - Border Radius: `50px` (fully rounded)
  - Padding: `16px 40px`
  - Font Weight: `800` or `700`
  - Transition: `all 0.3s ease`

## Section Layouts
- Use generous padding (e.g., `padding: 100px 0`).
- For icons or decorative elements, consider placing them in circular containers with a white background and subtle shadow (`boxShadow: 0 10px 25px -5px rgba(0,0,0,0.05)`).

Always apply these conventions to ensure a consistent, modern, and premium design across the application.
